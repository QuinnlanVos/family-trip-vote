# Family Trip Vote 🧭

A tiny, temporary site where the family votes on vacation spots and adds ideas.

- Live: https://quinnlanvos.github.io/family-trip-vote/
- Static site on GitHub Pages; shared votes and ideas live in one JSON document on [textdb.dev](https://textdb.dev) (free, no account).
- No logins: anyone with the link can vote, add ideas and (in theory) edit the shared data.
